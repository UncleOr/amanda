# העלאה ל-Google Play — מה לעשות, לפי הסדר

**מה שכבר סגור:** דירוג התוכן (IARC), בטיחות הנתונים, כתובת מחיקת המידע,
הטקסטים, האייקון, ה-feature graphic, ארבעה צילומי מסך והטריילר.

**מה שנשאר:** לבנות את הקובץ, להעלות, ולחבר את החתימה לדומיין.

---

## 0 · לבנות את ה-AAB

```bash
scripts\build-android.cmd
```

**צריך להריץ שוב גם אם הרצת אתמול** — שם הגרסה היה `y` והוא מופיע בחנות.
הוא `1.0.0` עכשיו, וזה נכנס לקובץ רק בבנייה.

בסוף:

```
android\app-release-bundle.aab     ← זה מה שעולה ל-Play
android\app-release-signed.apk     ← זה להתקנה ישירה על טלפון, לבדיקה
```

> **תתקין את ה-APK על הטלפון שלך לפני שאתה מעלה.** לוקח דקה ותופס דברים
> שמסך מחשב לא תופס. אם נפתחת שורת כתובת של דפדפן בראש המסך — זה שלב 3,
> והוא עוד לא קרה.

## 1 · ליצור את האפליקציה ב-Play Console

**Create app**, ואז:

| שדה | מה לענות |
| --- | --- |
| App name | `אמנדה \| משחק קלפים מפלצתי` |
| Default language | עברית (ישראל) |
| App or game | **Game** |
| Free or paid | **Free** |

> **Free זו החלטה שאי אפשר להחזיר.** אפליקציה חינמית לא יכולה להפוך לבתשלום
> אף פעם. זה בסדר — רכישות בתוך האפליקציה אפשריות גם ככה, וזה מה שדיברנו
> עליו.

חשבון מפתח אישי חייב **12 בודקים שנרשמו, ברציפות 14 יום**, לפני שאפשר בכלל

אם עוד תשנה דברים.

`Testing → Closed testing → Create track`, ושם רשימת אימיילים.

> ⚠️ **האימיילים לא נכנסים לריפו.** `UncleOr/amanda` ציבורי. הם נכנסים
> ל-Play Console ולשום מקום אחר.

יש לך שלושה. **צריך עוד תשעה.**

## 3 · החתימה של Play ← `assetlinks.json` ← **זה השלב שנופלים בו**

האפליקציה היא אתר עטוף (TWA). אנדרואיד פותח אותה במסך מלא **רק אם הדומיין
מצהיר שהוא מכיר את האפליקציה הזו.** ההצהרה הזו צריכה את טביעת האצבע של
המפתח שגוגל חותמת בו — **ומפתח ההעלאה שלך הוא לא אותו מפתח.**

אז הסדר הוא: להעלות קודם, ורק אחר כך לקבל את המספר.

1. להעלות את ה-`.aab` ל-closed testing
2. `Release → Setup → App integrity → App signing`
3. להעתיק את **SHA-256 certificate fingerprint** תחת **App signing key**
   — **לא** תחת Upload key
4. להחליף בו את `REPLACE-WITH-THE-PLAY-APP-SIGNING-FINGERPRINT` ב-
   `web/.well-known/assetlinks.json`
5. `git push` — Actions מעלה את זה לאוויר
6. לוודא: <https://playamanda.com/.well-known/assetlinks.json>

**הסימפטום כשזה לא נכון:** האפליקציה נפתחת עם **שורת כתובת של דפדפן בראש
המסך**. היא לא קורסת ולא מודיעה כלום — היא רק נראית כמו אתר במקום משחק.

> הקובץ יושב **בשורש הדומיין** ולא תחת `/play/`. Digital Asset Links מאמת
> מקור שלם, לא נתיב.

**מונטיזציה כבויה**. פרסומת לפני הסרטון מורידה אותו מדף החנות.
