# מפת המסכים — איפה כל כפתור

Or: *"מסכי הגדרות וכל מה שצריך — כל כפתור באיזה תפריט הוא נמצא."*

הרשימה המלאה נגזרת מהקוד ולא נכתבת ביד:

```bash
node scripts/screen-map.mjs
```

**136 פקדים ב-32 מסכים.** לוח הניהול לא נספר — הוא כלי למבוגר אחד ונשאר
בעברית.

---

## השלד

יש **שכבה אחת** של חלונות מלאים, ולכן אף פעם לא נפתחים שניים
(`game/useOverlay.ts`). כל מה שלא על הלוח הוא חלון כזה.

```
מסך הבית
├─ סרגל עליון  ────────────  הפעמון · גלגל השיניים
├─ לשחק עם בוט            → קרב (בנייה → פאניקה → קרב → תוצאה)
├─ לשחק עם חברים          → חדר · הזמנה
├─ עוד מודים              → MoreModes
├─ מגרש המשחקים           → לוח בלי שעון, שני הצדדים שלך
├─ איך משחקים             → Tutorial
├─ אתגרים                 → Challenges
├─ חדר המשחקים / הארנה    → ArenaTrack → כל הארנות
├─ האלבום                 → Album → CardDetailModal
├─ חנות נוחות             → Shop
├─ חברים                  → Friends → MatePeek
└─ הפרופיל (שמאל למעלה)   → Profile
```

**אין יותר שורת כפתורים קטנים למטה.** הכול עבר לגלגל.

## הסרגל העליון

שני כפתורים, ובמכוון:

| | איפה | למה שם |
| --- | --- | --- |
| **פעמון** | רק במסך הבית, רק עם חשבון | נושא מונה. התראה שצריך לפתוח תפריט כדי לגלות היא לא התראה |
| **גלגל שיניים** | תמיד | כניסה להגדרות. **תמונה ולא מילה** — מי שלא קורא את המשחק חייב למצוא את השפה |

נושא גם נקודה כתומה כשיש "מה חדש" שלא נקרא.

**למה רק שניים:** קודם היו ארבעה, השורה רצה עד x=177 וכפתור הפרופיל מתחיל
ב-136 — הפעמון ישב על 41 הפיקסלים הראשונים שלו. עכשיו השורה נגמרת ב-98.

במשחק עצמו הסרגל מחליף תוכן: שעון, שם השלב, ו**יציאה**.

## ההגדרות — מה יש בפנים

```
⚙ הגדרות
│
├─ מתגים            ← הסיבה שמישהו פותח את זה
│   ├─ צלילים        דולק / כבוי
│   ├─ מוזיקה        דולקת / כבויה
│   └─ שפה           עברית │ English   ← כל אחת בכתב שלה
│
├─ אותיות קטנות
│   ├─ אודות · פרטיות · נגישות   → About (שלוש לשוניות)
│   ├─ מה חדש                     → Updates  (+ נקודה אם לא נקרא)
│   └─ משהו לא עובד?              → Report
│
├─ גרסה 1a2b3c · מסך 844×390      [⟳ רענן]   ← הרענון רק בדפדפן
│
└─ ▸ מחיקת מידע                   ← סגור, אפור, רק עם חשבון
    ├─ מחיקת הפרטים שלי   → אישור
    └─ מחיקת החשבון שלי   → אישור
```

**למה המחיקה שם ולא בפרופיל:** Or: *"זה כמעט נראה כאילו אנחנו מזמינים אותו
לעשות את זה."* היא הייתה שני כפתורים ברוחב מלא ב-`btn-fight` — אותה מחלקה
כמו "המשך עם גוגל" שמעליהם וכמו הכפתור שמתחיל קרב. גוגל דורשת שהמסלול
**יימצא**, לא שיתחרה במשחק.

## מה שאין לו כפתור, בכוונה

| הכלל | איך הוא נלמד |
| --- | --- |
| משבצת ריקה מתמלאת במפלצת פירורים | כל משבצת ריקה **לובשת כבר** את מפלצת הפירורים, בשקיפות חמישית |
| צריך מלך | כתר ריק על הלוח |
| קלף על קלף (קומת קרקע) | סימן קטן בפינת המשבצת |
| משמר המלך | שני סימני מגן על שתי המשבצות |

זה התקן של המשחק: **אם משהו צריך הסבר, המשהו שגוי.** פקד אומר מה הוא
עושה בשלוש מילים לכל היותר, ואין פסקת פרוזה באף מסך משחק.

היוצא מן הכלל היחיד הוא לוח הניהול, שמותר לו להסביר את עצמו — הוא כלי
למבוגר אחד, ושם מספר שגוי עולה כסף.
