# הישגים של Play Games — מה זה דורש

Or: *"כמה זה מסובך לעבור לזה עכשיו? זה מה שביקשתי מלכתחילה, שנהיה מחוברים
בתוך גוגל פליי. אין לי בעיה לחכות לגרסה הבאה, רק לוודא שאפשר להוסיף
בקלות."*

**אפשר, וזה לא קשה. ושום דבר במה שעולה היום לא מקשה על זה אחר כך.**

---

## למה TWA לא יכול

לא עניין של מאמץ — **זה מבני.** TWA הוא לשונית כרום אמיתית שמוצגת בתוך
אפליקציה. אין בה גשר בין ג'אווהסקריפט לקוד אנדרואיד, **בכוונת התכנון** —
זה בדיוק מה שהופך אותה לדפדפן ולא ל-WebView. אז הדף לא יכול לקרוא
ל-Play Games, כמה שלא ננסה.

בדקתי את מה שנבנה: **אפס** התייחסויות ל-`games` או ל-`gms` במניפסט
ובבאנדל.

---

## מה צריך לזוז — וכמה מעט זה

כל העטיפה לאנדרואיד בריפו היא **שלושה קבצים**:

```
android/twa-manifest.json
scripts/android-prepare.cjs
scripts/build-android.cmd
```

**והמשחק לא יודע שהוא רץ באנדרואיד.** חיפשתי תלות — ההתאמה היחידה היא
`assetlinks.test.ts`, בדיקה על קובץ באתר.

אז המעבר הוא **החלפת העטיפה בלבד**: במקום bubblewrap, מעטפת עם WebView
(Capacitor הוא הדרך המתוחזקת) שטוענת את אותה כתובת. המשחק לא זז.

| | |
| --- | --- |
| החלפת העטיפה + בנייה ובדיקה על מכשיר | יום |
| התחברות ל-Play Games + גשר JS↔נייטיב | יום |
| הגדרת ההישגים בקונסולה וחיווט שלהם | חצי יום |
| **סה״כ** | **יומיים-שלושה**, ובדיקה על טלפון שרק אתה יכול לעשות |

## ומה שכבר מוכן בשבילם

האתגרים כבר מדברים באוצר מילים מוגדר של רגעים:

```ts
{ kind: "playCard"; cardId }   { kind: "placeSeries"; seriesId, row }
{ kind: "score"; least }       { kind: "win" }   { kind: "play" }
```

**אלה בדיוק הרגעים שהישג נתלה עליהם.** החיווט הוא קריאה אחת בכל מקום
שכבר סופר אתגר — לא מנגנון חדש.

---

## למה להעלות היום לא עולה כלום

אותו `packageId` (`com.asulins.amanda`) ואותו מפתח העלאה ← הגרסה הבאה
היא **עדכון לאותה אפליקציה**, לא רישום חדש. הבודקים נשארים, הדירוג
נשאר, שעון 14 הימים ממשיך לרוץ.

**ההפך נכון:** אם לא נעלה היום, השעון לא מתחיל — ואז Play Games רק
ידחה את הכל בשבועיים.

---

## שתי הסתייגויות אמיתיות

**1 · שתי זהויות.** התחברות ל-Play Games היא חשבון נפרד מהחשבון שלכם
ב-Supabase. ההתקדמות — אלבום, גביעים, יהלומים — תמשיך לשבת אצלנו;
ההישגים ישבו אצל גוגל. ילד שיתחבר ל-Play Games במכשיר אחר יראה שם את
ההישגים אבל לא את האלבום.

זו החלטה, לא באג, וכדאי להחליט אותה **לפני** שמחווטים: או שההישגים הם
קישוט נוסף, או ש-Play Games הופך לזהות הראשית וה-Supabase נקשר אליה.

**2 · WebView זה לא כרום.** זה Android System WebView. על מכשירים
מודרניים כמעט זהה, אבל זה משטח חדש לבדוק עליו. וצריך לשים לב למדיניות
*minimum functionality* של גוגל על עטיפות אתר — הישגים ומשחק אופליין
הם בדיוק הערך המוסף שעונה עליה, אבל זה דבר שכדאי להיות מודעים אליו.
