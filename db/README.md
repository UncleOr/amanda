# מסד הנתונים

פרויקט סופבייס: **amanda** (ארגון `Or Asulin`, אזור `eu-central-1`).

המיגרציות כאן הן מקור האמת. הן כבר הורצו על הפרויקט — הקבצים קיימים כדי
שהסכמה תהיה בגיט ולא רק בענן.

## העיקרון

**מה שקלף *הוא* נשאר ב-`data/`.** שמות, סטטיסטיקות, יכולות, נדירות — הכל
JSON שנבדק ב-Zod ונארז עם הבילד. **רק מה ש*לשחקן* יש** נמצא במסד.

אם סטטיסטיקות של קלף היו גם פה וגם שם, הן היו נפרדות ביום הראשון.

## הטבלאות

| טבלה | מה יש בה |
| --- | --- |
| `players` | מי אתה, גביעים, כוח אלבום, האם סיימת טוטוריאל |
| `player_cards` | אילו קלפים יש לך, כמה עותקים, ובאיזו רמה |
| `chests` | תיבות שהרווחת, ומה יצא מהן כשנפתחו |
| `matches` | היסטוריית קרבות — מי ניצח וכמה גביעים זזו |

## שתי החלטות שכתובות בסכמה

**עותקים הם תקציב הנחה.** אפשר לשים קלף על הלוח כמספר העותקים שיש לך ממנו.
ככה עותק כפול שווה משהו כבר מהשני, לא רק כשמגיעים לסף שדרוג. ואפשר במקום
זה *להוציא* עותקים כדי להעלות רמה — רוחב או גובה, וזו הבחירה של השחקן.

**שני מספרים, לא אחד.** `trophies` מודד מיומנות, `album_power` מודד כמה זמן
השקעת. התאמה לפי גביעים בלבד היא בדיוק מה שגורם למשחק עם רמות קלפים להרגיש
לא הוגן — וזה מה שאור זיהה כשאמר "חזקים ב-14 רמות ממני".

## אבטחה

RLS דולק על כל הטבלאות. שחקן **קורא רק את השורות שלו**, ולא כותב כלום חוץ
משם התצוגה. גביעים, עותקים, רמות ותכולת תיבות נכתבים רק מהשרת — אחרת כל אחד
היה עורך אותם מהדפדפן.
